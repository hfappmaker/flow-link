# 競合調査メモ

## 2026-06-06 公開案件検索

- Upworkはキーワード検索に加えて、スキル、単価、勤務地などの複数フィルターで候補を絞り込ませている。
- Indeed系の求人検索でも、キーワード、勤務地、給与、雇用形態、リモート可否、投稿日などの条件指定が基本になっている。
- Flow Link MVPでは、まず公開案件一覧に「キーワード + リモート可否」の最小フィルターを追加する。
- 今後の拡張候補は、単価帯、稼働率、契約期間、スキルタグ、保存検索。

## 2026-06-06 応募者管理

- 採用管理・求人管理系では、応募者をステータス別に絞り込み、未処理候補を優先して確認できることが重要。
- Greenhouse系の応募体験では、PDFだけでなく構造化された応募情報が候補者レビューや検索に効く。
- Flow Link MVPでは、企業の応募者一覧にステータスタブ、候補者キーワード検索、PDF/職務経歴の充足表示を追加する。

## 2026-06-06 応募準備チェック

- フリーランスマーケットプレイスでは、応募前にプロフィールや職務経歴の完成度を上げさせる導線が応募品質に効く。
- Flow Link MVPでは、フリーランスダッシュボードに応募準備チェックを追加し、案件詳細の応募ボタンでも未完了項目を案内する。
- 応募のServer Action側でも、プロフィール、職務経歴フォーム、履歴書PDF、職務経歴書PDFが揃っていることを検証する。

## 2026-06-06 面談日程調整

- 採用/面談調整ツールでは、チャット本文だけでなく「次に何をするか」「候補日時」「確定日時」「会議URL」を別枠で見せると迷いが減る。
- Flow Link MVPでは、面談チャットに次アクション、最新候補、確定日時、会議URLのサマリーを追加する。
- 候補日時がある場合は、候補ごとに「この日時で確定」できるフォームを表示する。
