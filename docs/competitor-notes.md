# 競合調査メモ

## 2026-06-06 公開案件検索

- Upworkはキーワード検索に加えて、スキル、単価、勤務地などの複数フィルターで候補を絞り込ませている。
- Indeed系の求人検索でも、キーワード、勤務地、給与、雇用形態、リモート可否、投稿日などの条件指定が基本になっている。
- Flow Link MVPでは、まず公開案件一覧に「キーワード + リモート可否」の最小フィルターを追加する。
- 今後の拡張候補は、単価帯、稼働率、契約期間、スキルタグ、保存検索。

## 2026-06-06 応募者管理

- 採用管理・求人管理系では、応募者をステータス別に絞り込み、未処理候補を優先して確認できることが重要。
- Greenhouse系の応募体験では、PDFだけでなく構造化された応募情報が候補者レビューや検索に効く。
- Flow Link MVPでは、企業の応募者一覧にステータスタブ、候補者キーワード検索、PDF/職務経歴の充足表示を追加する。

## 2026-06-06 応募準備チェック

- フリーランスマーケットプレイスでは、応募前にプロフィールや職務経歴の完成度を上げさせる導線が応募品質に効く。
- Flow Link MVPでは、フリーランスダッシュボードに応募準備チェックを追加し、案件詳細の応募ボタンでも未完了項目を案内する。
- 応募のServer Action側でも、プロフィール、職務経歴フォーム、履歴書PDF、職務経歴書PDFが揃っていることを検証する。

## 2026-06-06 面談日程調整

- 採用/面談調整ツールでは、チャット本文だけでなく「次に何をするか」「候補日時」「確定日時」「会議URL」を別枠で見せると迷いが減る。
- Flow Link MVPでは、面談チャットに次アクション、最新候補、確定日時、会議URLのサマリーを追加する。
- 候補日時がある場合は、候補ごとに「この日時で確定」できるフォームを表示する。

## 2026-06-07 応募時の提案情報

- FindyはAIでエンジニアのスキルと求人票を分析して最適なマッチングを目指している。https://findy.co.jp/en/service/
- Xpert Directは「No recruitment agencies required」と、直接チャット、直接交渉、オファー/契約までの流れを前面に出している。https://xpertdirect.io/
- OB ProMatchはマッチ後のチャット、ビデオ面談、透明なパイプラインを価値として訴求している。https://obpromatch.com/en/
- Flow Link MVPでは、応募時にフリーランスが貢献内容、稼働開始目安、連絡希望を企業へ送れる提案情報を追加し、企業の応募者一覧、応募詳細、面談チャットのハンドオフで確認できるようにする。

## 2026-06-08 面談調整の継続管理

- レバテック系サービスは、案件申し込み後の商談設定、成立、単価交渉、契約、参画中フォローまでサポートする流れを案内している。https://creator.levtech.jp/ https://freelance.levtech.jp/service/onsite/
- レバテックフリーランスのヘルプでは、案件提案・相談、検索、掲載内容、標準的な支払いサイトなど、応募前後の不安を減らす情報を整理している。https://freelance.levtech.jp/help/
- Findy Freelanceは、オンライン面談で経歴・希望条件・中長期キャリアを確認して案件紹介につなげる流れを案内している。https://info.freelance.findy-code.io/lp001
- Flow Linkでは、書類選考OK後に企業が候補日時の確定や会議URL共有を見落とさないよう、企業ダッシュボードに面談調整の未完了キューを追加する。

## 2026-06-08 検討リストから応募準備への接続

- Findy Freelanceは、スタートアップ・自社開発・フルリモート案件を中心に、ユーザーサクセスがスキル、キャリアプラン、希望する働き方を聞いて案件提案や面談対策、契約締結まで支援すると説明している。https://freelance.findy-code.io/articles/findy_freelance
- Findy Freelanceの公開トップでは、案件例に稼働日数、リモート、技術スタック、月単価、案件タグを並べ、週2〜3日・フルリモートなど働き方で選びやすいことを訴求している。https://freelance.findy-code.io/
- レバテックフリーランスのマイページ紹介では、提案案件の管理、経験・希望条件の設定、商談スケジュール確認、気になる案件のお気に入り登録を一元化する価値を案内している。https://freelance.levtech.jp/service/platform/member/
- Flow Linkでは、保存した案件ごとに、提案文で伝える一致点、面談で確認したい条件、応募前の残タスクを整理する応募準備シートを追加し、検討リストを応募行動に近づける。

## 2026-06-09 企業の案件運用トリアージ

- Findy Freelanceは、登録後に案件詳細やトレンド情報を確認し、ユーザーサクセス面談、企業とのマッチング面談、契約・稼働開始へ進む流れを案内している。https://freelance.findy-code.io/lp01
- レバテックフリーランスのマイページ紹介では、提案案件管理、商談スケジュール、気になる案件、おすすめ案件などを一元管理する価値を案内している。https://freelance.levtech.jp/service/platform/member/
- OB ProMatchは、マッチ後のチャット、ビデオ面談、契約、請求・支払いまでの流れと、各ステップの透明性を訴求している。https://obpromatch.com/en/
- Flow Linkでは、企業の案件一覧に公開状態、未選考、対応期限、条件不足、受付停止、面談調整のフィルターと優先順を追加し、企業が複数案件の運用で次に見るべき案件を見失わないようにする。
